# 47 — Verificação de identidade exigida para usar os serviços

Pedido: verificação deixa de ser opcional. Corrigido pelo usuário: "Faça a verificação ser obrigatória caso o usuário queira fazer uso dos serviços ou o profissional para receber oportunidades."

- [x] Recusa com motivo e como corrigir (V19), motivos prontos no painel do administrador
- [x] Site: Contratar e Oportunidades mostram o passo a passo, "em análise" e "recusada" com motivo e correção
- [x] Início: item "Identidade verificada" em Sua conta; contador de oportunidades só para quem pode recebê-las
