# 48 — Um tipo de conta para cada papel

Pedido: "Quero que você crie outros tipos de conta, porque hoje existe também o suporte, que usa cliente, e não pode. Cada tipo de usuário tem que ter seu tipo, não usar o que tiver."

## Passos
- [x] Levantar como cada papel é guardado hoje (cliente, profissional, administrador, moderador, financeiro, suporte)
- [x] Servidor: cada papel com seu próprio tipo de conta; equipe nunca como cliente ou profissional; migração das contas existentes
- [x] Site: abas e telas por tipo, sem cair na área de cliente
- [x] Testes e docs
